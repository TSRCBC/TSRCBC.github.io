# 奇農 CHINON GitHub Pages 版本

這是依原 Wix 網站內容重新設計的多頁式靜態網站。

## 上傳 GitHub Pages
1. 建立一個 GitHub Repository。
2. 將本資料夾所有檔案上傳到 repository 根目錄。
3. Settings → Pages → Deploy from a branch → `main` / `(root)`。
4. 等待 GitHub 提供公開網址。

## 目前圖片狀態
目前 HTML 直接引用原 Wix 的 `static.wixstatic.com` 圖片網址，目的是先完成版型與內容轉移。正式脫離 Wix 時，建議把圖片下載到 `images/`，再把 HTML 中的網址改成相對路徑。

## 聯絡表單
現在使用 `mailto:` 示範。若要自動寄信、不開啟使用者郵件程式，可改接 Formspree 或 Google Apps Script。
