CHINON V7｜款式 3「溫暖生活」
================================

這一版就是你選的第 3 款：
溫暖、日常、自然光、米白＋茶棕＋橄欖綠。

保留舊案資訊：
- 首頁品牌主張
- 關於奇農
- 製茶堅持
- GABA 桑茶
- 秘魯黃金瑪卡
- 檢測證書
- 相關資訊
- 聯繫我們
- 電話、手機、Email、苗栗營運分處
- 原本商品圖、製茶圖、品牌素材與證書圖

重新製作：
- 全新乾淨 HTML 結構
- 全新暖色生活感 CSS
- 不再依賴舊 Grapes 亂數 ID
- 不鎖死中文字型
- 桌機／平板／手機 RWD
- V7 /editor/ 可讀取全部 8 個頁面

編輯器保留 V5 的 Wix-like 基本功能：
- 新增文字、標題、圖片、按鈕
- 超連結
- 換圖片
- 背景圖片
- 字型／顏色／陰影
- 區塊、雙欄、三欄、圖形、影片
- 自由移動、縮放、複製、刪除
- 圖層
- Undo / Redo
- 新增頁面
- HTML / CSS
- 下載網站 ZIP

安裝：
1. 解壓縮 V7 ZIP。
2. 用 github.dev 將 ZIP 裡所有內容覆蓋到 TSRCBC.github.io 根目錄。
3. Commit & Push。
4. 等 github-pages 綠勾。
5. 正式網站：https://tsrcbc.github.io/
6. 編輯器：https://tsrcbc.github.io/editor/

如果瀏覽器仍顯示舊版：
Ctrl + Shift + R
