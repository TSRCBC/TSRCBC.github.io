CHINON 自助網站編輯器 V5
=========================

這版是「全新網站 + 自架免費編輯器」，不沿用舊 TSRCBC.github.io 網站內容。

它不是完整 Wix，但已包含你要求的常用基礎功能：

新增內容
- 文字
- 標題
- 圖片
- 按鈕
- 連結文字
- 區塊
- 雙欄
- 三欄
- 分隔線
- 留白
- 圖形
- YouTube 影片

編輯功能
- 雙擊文字直接改字
- 中文字型選擇
- 字體大小 / 粗細 / 斜體 / 底線
- 文字顏色
- 背景顏色
- 文字對齊
- 文字陰影
- Box Shadow
- Border / Border Radius
- 透明度
- Margin / Padding
- Width / Height
- Flex / Grid / Gap
- Background Image
- 換圖片
- 超連結 / 新分頁
- 移除超連結
- 精確自由移動
- 縮放框
- 複製元件
- 刪除元件
- 上一層 / 下一層 / 最上層
- 恢復原位
- Undo / Redo

頁面
- 新增頁面
- 改頁名 / 檔名
- 刪除頁面
- 桌機 / 平板 / 手機預覽

進階
- HTML / CSS 編輯
- 本機自動儲存
- 下載完整網站 ZIP
- 圖片在匯出 ZIP 時自動整理到 assets/uploads/

安裝
----
1. 建議先把 TSRCBC.github.io 舊網站檔案備份。
2. 如果你確定舊網站全部不要，可以刪掉舊 index.html、其他舊 HTML、styles.css、main.js、舊 assets。
3. 保留 GitHub Pages 設定。
4. 把本 ZIP 解壓後的以下內容上傳到儲存庫根目錄：
   index.html
   styles.css
   main.js
   editor/
5. Commit changes。
6. 等 github-pages 綠勾。
7. 正式網站：
   https://tsrcbc.github.io/
8. 編輯器：
   https://tsrcbc.github.io/editor/

平常使用
--------
新增文字：＋文字 → 雙擊修改 → 右側選字型/顏色。
新增圖片：＋圖片 → 從電腦選照片。
超連結：先選文字/圖片/按鈕 → 🔗 超連結 → 輸入網址。
自由移動：先選元件 → ✥ 自由移動 → 再直接抓著拖。
換顏色：右側 Styles，或用 🎨 快速樣式。
背景圖片：選區塊 → 背景圖。
修改完成：儲存 → 下載網站 ZIP → GitHub 根目錄 Upload files → 覆蓋 → Commit。

重要
----
「儲存」是存在目前瀏覽器。
真正更新公開網站，要按「下載網站 ZIP」後上傳 GitHub。
