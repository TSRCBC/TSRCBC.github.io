CHINON V10.6 CLEAN｜本次修正報告
===================================

你回報的兩個問題，根因已確認：

1. 製茶堅持滑到中間又出現第二個橫幅、重新介紹一次
   原因不是正常設計。
   你上傳的 craft.html 內有尚未清掉的 Git merge conflict：
   <<<<<<< HEAD / ======= / >>>>>>>
   而且同一頁實際包含 2 個 <main>、2 個 subhero，所以瀏覽器真的把頁面內容顯示了兩遍。

2. 手機右上三條線無法切換頁面
   同一批未解決 conflict 也存在 certificates/contact/craft/gaba/info/maca。
   HTML 結構重複／失真後，導覽列與 JS 綁定會變得不可靠。

V10.6 CLEAN 已做：
- 8 個正式頁面：Git conflict marker 全部清為 0。
- craft.html：只保留一份製茶堅持內容，不再有第二個橫幅。
- main.js：手機選單重新強化，支援：
  開啟／關閉、點連結後收起、點外面收起、ESC 收起、回桌機自動收起。
- 手機 Logo 旁保留「奇農 / CHINON」，不再只剩 Logo。
- Preview 8 頁全部從乾淨正式頁重新建立。
- 首屏之外圖片加 loading=lazy / decoding=async，改善初次開啟速度。
- Editor 更新為 V10.6 CLEAN。
- Editor 新增「找WIX圖片」：
  每按一次會跳到本頁下一張仍使用 wixstatic.com 的圖片；
  接著按「換圖片」上傳你的修改照片。
  Preview/正式發布後，新圖會轉成 GitHub assets/uploads 本地圖片。

目前正式 8 頁仍有 Wix 圖片引用合計：40 張。
這些沒有強制刪除，因為你說要由你自己上傳修改過的照片替換。
